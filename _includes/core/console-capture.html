{%- comment -%} =================================================================== CONSOLE CAPTURE — early console/error ring buffer =================================================================== File: console-capture.html Path: _includes/core/console-capture.html Purpose: Load the fleet feedback kit's capture buffer HIGH in — before the theme's deferred scripts run — so the page-feedback widget can attach the logs and JS errors that led up to a report. Renders: only when page_feedback.enabled AND page_feedback.capture_logs. This used to be ~60 lines of inline ES5 maintained here. It is now the fleet kit's capture.js, VENDORED to assets/js/fleet-feedback-capture.js (bamr87/bamr87 templates/feedback/capture.js — drift check (i) holds the copy to the hub's). Two things came with the move: the buffer shape is now the one FleetFeedbackCore reads, so the theme's widget and the fleet's web component file byte-identical issues; and every captured line is REDACTED before it enters the ring (bearer/API keys, JWTs, GitHub tokens, email addresses), so a secret cannot be previewed, copied, or filed. Loaded blocking rather than deferred, and that is the point: a buffer installed after parsing misses exactly the load-time failures worth reporting. It is ~4 KB, and it REPLACED ~3.7 KB of inline script, so the head got smaller — which also buys back room for the charset meta that has to land in the first 1024 bytes (issue #372). Privacy: in-memory only, never persisted, never sent anywhere until the reader opens the modal, reviews the captured lines, and submits. Any single entry is truncated; the buffer is a fixed-size ring (page_feedback.log_limit, default 40). Depends on: assets/js/fleet-feedback-capture.js (vendored, no CDN). =================================================================== {%- endcomment -%} {%- if site.page_feedback.enabled and site.page_feedback.capture_logs -%} {%- comment -%} The ring size is site configuration, so it is applied after the buffer installs rather than baked into the vendored file (which must stay byte-identical to the hub's). {%- endcomment -%} {%- if site.page_feedback.log_limit -%} {%- endif -%} {%- endif -%}
