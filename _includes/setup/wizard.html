Dependencies: Bootstrap 5.3, assets/js/setup-wizard.js, _sass/components/_setup-wizard.scss Environment: Development only (guarded by calling page) Layout (T-040 / #408) — three columns at lg+, stacked below: 1. Left — vertical stepper (#wizardTabs). Replaces the nav-pills row. Steps carry .is-done / .is-active / .is-locked; an upcoming step is `disabled` until every earlier step validates, and going BACK is always allowed. 2. Middle— the step panes (#wizardTabContent). The container gets a min-height equal to the TALLEST pane (measured in JS, since CSS cannot know it), and each pane's nav row is pinned to the bottom with mt-auto — together that is what stops Back/Next moving vertically between steps. 3. Right — the live YAML preview. Sticky, present at EVERY step (it used to exist only inside step 5), regenerated on every input, with Copy and Download always enabled. Draft persistence: every field is mirrored to localStorage under `zer0-setup-draft` (debounced 300ms) and restored on load; the "Draft saved" chip acknowledges it, and downloading the file clears it. NOTE: T-040 also asked to "remove the N% complete math". There is no such code in this component and there never was — see the analysis on #408. Nothing was removed for that clause, and no percentage indicator should be added in order to remove one. =================================================================== {% endcomment %}
