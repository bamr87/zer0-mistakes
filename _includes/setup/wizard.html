{% comment %} ───── Step 1: Connect ───── {% endcomment %}

Connect Claude

The builder runs entirely in your browser. Connect Claude through the local dev proxy and it can also check your machine, read the theme's source, fill in these forms, write your project and start Docker for you.

Looking for the dev proxy…
Checking

How to connect (once, on your machine)

  1. 1
    Mint a Claude Code OAuth token

    Requires the Claude Code CLI and a Claude Pro/Max login. The token is personal — it never leaves your machine.

    claude setup-token
  2. 2
    Put it in .env at the theme's root

    .env is git-ignored. Copy .env.example if you do not have one yet.

    CLAUDE_CODE_OAUTH_TOKEN=sk-ant-oat01-…
  3. 3
    Start the dev proxy next to the site

    Node 20.6+ reads the file for you. Leave it running while you use the builder.

    node --env-file=.env templates/deploy/chat-proxy/dev-proxy.mjs
What the proxy is allowed to do
  • Run a fixed list of read-only version checks (Docker, Git, gh, VS Code, Node, Claude CLI).
  • Read text source files inside the theme checkout — never .env, keys or build output.
  • Write generated files only into a new folder beside the theme, never inside it, never over existing files unless you say so.
  • Run docker compose up / ps / logs / down in that folder — nothing else.
No proxy? Continue anyway. Every step still works and the Build step gives you the files and the commands to run yourself.
