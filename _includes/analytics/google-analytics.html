{% comment %} Feature: ZER0-038 {% endcomment %} {%- comment -%} Consent gate. When the site requires consent, gtag.js is not requested and no _ga cookie is set until the visitor accepts the "analytics" category in the cookie-consent banner (localStorage "zer0-cookie-consent"). Accepting loads it on the spot (the banner dispatches `cookieConsentChanged`), so no reload is needed. A site configures its consent posture once: this follows `posthog.privacy.require_consent`, the same flag that gates PostHog and the page-view counter. `google_analytics_require_consent: true|false` overrides it for GA alone, for a site that runs GA without PostHog. With neither flag set, GA loads exactly as before. {%- endcomment -%} {%- assign ga_require_consent = false -%} {%- if site.posthog.privacy.require_consent -%}{%- assign ga_require_consent = true -%}{%- endif -%} {%- if site.google_analytics_require_consent == true -%}{%- assign ga_require_consent = true -%}{%- elsif site.google_analytics_require_consent == false -%}{%- assign ga_require_consent = false -%}{%- endif -%}
