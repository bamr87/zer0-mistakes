{% comment %} Feature: ZER0-083 {% endcomment %} {%- comment -%} Component: recipe-duration (value resolver — emits a bare string) Path: _includes/components/recipe-duration.html Purpose: Format a duration given in MINUTES, either for humans ("1 hr 30 min") or as an ISO 8601 duration for schema.org ("PT1H30M"). Params: minutes (number, required) format (string, optional, default: "human") — "human" | "iso" Depends on: nothing (pure Liquid arithmetic) Notes: Emits nothing for a missing or zero duration, so callers can test the captured value and skip the whole row. Days are not special-cased — a 3-day cure reads as "72 hr", which is how recipes actually write long ferments. Liquid `assign` writes to the GLOBAL scope even inside an include, so a helper called several times from one caller will clobber the caller's variables if the names collide. Every variable here is therefore prefixed `_rd_`, and the other recipe components use their own prefixes. Keep that up when editing.
