{% comment %} Feature: ZER0-078 {% endcomment %} {%- comment -%} Component: language-toggle Path: _includes/components/language-toggle.html Purpose: Switches between the English original and its machine-generated translations (scripts/translate.rb). Shows the source language plus every configured target language; targets without a generated translation for the current page render as disabled entries. Params: variant (string, optional, default "navbar") - "navbar" — compact dropdown for the header utility cluster - "panel" — self-contained "Language" section for the Settings offcanvas (components/info-section.html), rendered as an always-visible list of choices with its own
heading Reads: page.lang / page.url / page.translation_source_url and the generated _data/i18n/manifest.yml. Depends on: site.translation.* config, site.data.i18n.manifest, _data/i18n/languages.yml (display names), core/i18n.html, Bootstrap 5 dropdown (navbar variant only), Bootstrap Icons (bi-translate) Notes: Renders nothing when translation is disabled or no target languages are configured. The chosen language is remembered in localStorage("zer0-lang") for future UX (no auto-redirect). Must NOT be include_cached — the menu is page-dependent.
