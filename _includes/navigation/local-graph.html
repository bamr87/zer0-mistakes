{% comment %} Feature: ZER0-045 {% endcomment %} {%- comment -%} =================================================================== LOCAL GRAPH SIDEBAR — collapsible page-scoped graph =================================================================== File: local-graph.html Path: _includes/navigation/local-graph.html Included from: _includes/core/footer.html after (body-level) Purpose: Renders a collapsible, page-scoped graph of the current page and its immediate wiki-link neighbors in a separate side panel. Behavior: - Reads /assets/data/wiki-index.json - Finds the current page by window.location.pathname (with title/basename fallback for permalink quirks) - BFS depth=1 by default (current + direct neighbors, in & out) - Renders the current page as a single-node graph when it has no neighbors - Hides itself if the current page is not in the wiki-index or the index can't be loaded - Lazily loads the vendored cytoscape.js (assets/vendor/cytoscape/, no CDN) Opt-out: set `local_graph: false` in page front matter. Configurable depth: `local_graph_depth: 2` in page front matter (default 1). The panel's depth selector (1–3) and incoming/outgoing switches override it per-browser via localStorage (zer0.obsidianLocalGraph.v1). =================================================================== {%- endcomment -%} {%- comment -%} Shared visibility resolver — sets sidebar_enabled {%- endcomment -%} {%- include navigation/sidebar-config.html -%} {%- if page.local_graph != false and sidebar_enabled -%} {%- assign lg_depth = page.local_graph_depth | default: 1 -%}
