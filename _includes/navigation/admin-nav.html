{% comment %} Feature: ZER0-050 {% endcomment %} {% comment %} =================================================================== ADMIN NAV — Data-driven sidebar navigation for admin/settings pages =================================================================== File: admin-nav.html Path: _includes/navigation/admin-nav.html Purpose: Renders a vertical nav list for administrative pages. Items are read from _data/navigation/admin.yml and listed under their `group:` (Configure / System / Links), groups in order of first appearance. Highlights the active page based on page.url or page.admin_section matching. Params: id_prefix (string, optional, default: "admin-nav") — prefix for the group-label ids. _layouts/admin.html renders this include twice (desktop sidebar + mobile offcanvas), so each call passes its own prefix to keep the ids unique. Markup: One .nav.nav-pills list. Each group is a list item holding a small-caps label (plain text, not a heading, so the page outline stays h1 → content) and a nested list named by that label via aria-labelledby. Items without a `group:` render in one unlabelled list, so a data file written before groups existed keeps working (its external links keep the
). Active item: .active + fw-semibold + aria-current, drawn as a skin tint by _sass/components/_admin-nav.scss (no solid primary fill). Counts render as plain numerals; statuses as a coloured dot (aria-hidden) plus a word.
