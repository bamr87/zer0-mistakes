# Evidence: the AI chat panel title no longer skips heading levels (issue #586, T-055)

`_includes/components/ai-chat.html` titled the chat dialog with a bare `<h6 id="aiChatTitle">`, chosen for its small type. The panel renders under `<body>`, outside `<main>`, after the cookie dialog's h3 category headings, so on every page that ships the chat a screen-reader user walking by heading met h3 → h6, a two-level jump (WCAG 1.3.1). The fix is `<h2 id="aiChatTitle" class="h6 mb-0 fw-semibold">`: the tag states the depth of a top-level dialog (one below the page `<h1>`, like the cookie dialog's `<h2>` title), the `.h6` utility keeps the size, and the `id` that `aria-labelledby` points at is unchanged. The change is meant to be **visually inert**.

Generated by [`test/visual/ai-chat-heading-evidence.mjs`](../../ai-chat-heading-evidence.mjs) against a dev build (`_config.yml,_config_dev.yml,_config_snapshots.yml`, where the chat is on), with `BEFORE_URL` pointing at a build of `main` at 61be170. For each scenario it opens the chat panel, records the heading walk (the previous heading in DOM order → the chat title) and the header render, then reproduces the pre-fix state by reverting exactly the diff in the live DOM (`<h2 class="h6 …">` → `<h6 …>`, same attributes and children) and records both again. It also renders the same header from the real `main` build. Captures run with reduced motion and animations disabled, because two screenshots of the same open panel differ otherwise.

- `01-chat-header-before-after.png`: home at 1280px in light and dark mode, `/docs/` at 1280px and `/404.html` at 390px. The heading walk h3 → h6 (skips 2) becomes h3 → h2, and the header renders byte-identical to the reverted DOM and to the `main` build.
- `metrics.json`: per scenario, the before/after heading walk, the computed font-size, weight, line-height and margin (16px / 600 / 19.2px / 0 on both sides), whether `aria-labelledby` still resolves to the title, and the two byte-equality results (`pixelIdentical`, `baseBuildIdentical`), true in all four.

The regression test is `test/visual/core/heading-outline.spec.js`: `#aiChatPanel` joins `CHROME_REGIONS`, and each region's outline is now walked from the page's `<h1>`, so a region whose only heading is an `<h6>` fails (`h1 -> h6 at "Zer0 Assistant"`). The "small type does not mean a deep level" test builds its selector list from `CHROME_REGIONS`, so it covers the chat panel too.
