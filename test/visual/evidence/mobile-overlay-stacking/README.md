# Evidence — mobile overlay stacking fix (`.zer0-bg-body`)

Before/after proof for the removal of the child-elevation rule in
`_sass/theme/_backgrounds.scss` (the body now isolates with the noise layer at
`z-index: -1` instead of forcing `position: relative; z-index: 1` on every
direct child).

Generated by [`test/visual/mobile-overlay-stacking-evidence.mjs`](../../mobile-overlay-stacking-evidence.mjs)
at 390×844 against two local builds of this repo (BEFORE = the commit prior to
the fix, AFTER = the fix). Regression suite:
[`test/visual/features/mobile-overlay-stacking.spec.js`](../../features/mobile-overlay-stacking.spec.js)
— verified to FAIL against the BEFORE build (sidebar scenario) and PASS against
the AFTER build.
