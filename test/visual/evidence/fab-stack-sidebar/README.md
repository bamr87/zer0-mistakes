# Evidence — docs-sidebar FAB vs local-graph FAB (#571)

Below `lg` (< 992px), a page with both the docs-sidebar FAB (`#sidebarFab`, slot 2) and the Obsidian local-graph FAB (`#obsidianLocalGraphFab`) rendered the two at the identical box on the left edge; the graph FAB (z-index 1060 > 1055) sat on top and took every tap meant for the sidebar, so the docs navigation could not be opened on mobile. The fix (`_sass/core/_obsidian.scss`) moves the graph FAB to slot 3 (`offset + 2 × (size + gap)`) below `lg` whenever `#sidebarFab` is on the page; at `lg`+ the sidebar FAB is `d-lg-none`, so the graph FAB keeps slot 2.

Generated by [`test/visual/fab-stack-sidebar-evidence.mjs`](../../fab-stack-sidebar-evidence.mjs) (`node test/visual/fab-stack-sidebar-evidence.mjs`): the real theme stylesheet compiled with dart-sass, the real FAB markup, host Chromium. The FABs are `position: fixed`, so the geometry matches the live site. BEFORE re-applies the old slot-2 rule.
