## What changed, and why the chrome moved

`_sass/core/code-copy.scss` shipped a bare `.button, button:not(.copy)` rule — an element selector with no scope, living in a code-copy component partial. At specificity (0,1,1) it out-ranked Bootstrap's `.btn`, so **every** `<button>` on the site that was not the theme's own copy button was rendered with `padding: 0 20px` (no vertical padding at all), `font-size: 11px`, and a hardcoded `#bbb` border. Issue #412 was filed by a downstream consumer who had to win a specificity fight to style its own button; the theme's own chrome was being flattened by the same rule the whole time.

Scoping the rule to `.code-block-header` / `pre.highlight` is therefore not a no-op refactor — it hands every button back its intended size. That is what these images show, and it is why the nine pixel baselines moved.
