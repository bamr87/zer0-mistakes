# Document d'exigences produit

Le thème Jekyll Zer0-Mistakes conserve son PRD complet — vision, personas d'utilisateurs, exigences fonctionnelles, architecture technique, indicateurs clés de performance, feuille de route et critères d'acceptation — comme référence pour les contributeurs dans la documentation technique du dépôt.

## Ce que vous y trouverez

Le PRD documente la vision produit, les personas cibles, le backlog de fonctionnalités, les contraintes d'architecture technique, les définitions des KPI et les critères d'acceptation des versions pour la gem `jekyll-theme-zer0`. Il est conservé sous l'arborescence `docs/` du dépôt (exclue de la génération Jekyll), aussi les copies canoniques sont-elles reliées ci-dessous sur GitHub :

- **[Exigences produit →](https://github.com/bamr87/zer0-mistakes/blob/main/docs/architecture/prd-requirements.md)** — vision, personas, exigences et critères d'acceptation
- **[Feuille de route et métriques →](https://github.com/bamr87/zer0-mistakes/blob/main/docs/architecture/prd-roadmap.md)** — jalons, KPI et suivi des livraisons
