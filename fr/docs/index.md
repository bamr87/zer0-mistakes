# Documentation Zer0-Mistakes

Bienvenue dans la documentation du thème Jekyll Zer0-Mistakes. Cette section contient des **guides destinés aux utilisateurs** pour installer, configurer et personnaliser le thème.

> **Système de documentation à deux niveaux :** Ce site (`/docs/`) contient les guides utilisateur — comment *utiliser* le thème. Pour les références destinées aux contributeurs et mainteneurs (architecture, automatisation des versions, fonctionnement interne), consultez le [répertoire `docs/`](https://github.com/bamr87/zer0-mistakes/tree/main/docs) dans le dépôt.
