# Prise en main

Bienvenue dans Zer0-Mistakes ! Choisissez votre parcours pour démarrer avec le thème.

## Parcours de démarrage rapide

| Parcours | Méthode | Idéal pour |
|------|--------|----------|
| **A** | [Assistant d'installation IA](quick-start/) | Créer un nouveau site (recommandé) |
| **B** | Dépôt modèle GitHub | Copie en un clic de l'ensemble du dépôt |
| **C** | GitHub Codespaces | Développement dans le cloud sans installation |
| **D** | Fork/Clone | Personnalisation du site et du thème |
| **E** | Thème distant | GitHub Pages sans copier de fichiers |
| **F** | Gem Ruby | Flux de travail Jekyll traditionnel |

## Guides de cette section

- **[Guide de démarrage rapide](quick-start/)** — Plusieurs méthodes d'installation, de l'assistant IA à la configuration manuelle
- **[Guide du thème](theme-guide/)** — Guide complet pour utiliser et personnaliser le thème

## Prérequis

Pour la plupart des méthodes d'installation, vous aurez besoin de :

- **Docker Desktop** (recommandé) ou Ruby + Bundler
- **Git** pour le contrôle de version
- **Éditeur de texte** (VS Code recommandé)

## Étapes suivantes

Après l'installation :

1. [Configurez votre site](/docs/front-matter/) — Définissez le front matter de vos pages
2. [Activez les fonctionnalités](/docs/features/) — Ajoutez des diagrammes, commentaires et analyses
3. [Déployez votre site](/docs/deployment/) — Publiez sur GitHub Pages ou Netlify
